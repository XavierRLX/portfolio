# Estratégia de Conteúdo

## Objetivo
Fazer o portfólio representar o trabalho atual. A regra é mostrar menos projetos e explicar melhor os que realmente demonstram arquitetura, produto, backend, dados, mobile e IA.

## Projetos principais

### 1. AWX / All Wheels Experience
Posicionamento: principal projeto autoral.

Pontos que devem aparecer:
- plataforma de gestão automotiva;
- Next.js, React e TypeScript;
- Supabase/PostgreSQL, Auth, RLS e RPCs;
- histórico de manutenção, despesas, FIPE e compartilhamento/transferência;
- web + Android/iOS via Capacitor;
- integrações e experimentos com IA/RAG quando a informação estiver comprovada no projeto.

### 2. Cursos Pugliese / Plataforma-Curso
Posicionamento: produto full stack com regras de negócio e segurança.

Pontos que devem aparecer:
- plataforma de cursos com papéis admin/teacher/student;
- Next.js App Router e TypeScript;
- Supabase Auth SSR e PostgreSQL;
- RLS, RPCs transacionais e autorização server-side;
- cursos, módulos, aulas, exercícios, progresso, planos, entitlements e turmas;
- trabalho explícito de segurança e preparação de produção.

Observação: o repositório é privado. O portfólio pode mostrar o produto e stack sem expor código privado.

### 3. Galerows
Posicionamento: produto consumer/mobile e experimentação de jogos sociais.

Pontos que devem aparecer:
- coleção de jogos para grupos;
- React + TypeScript + Vite;
- testes com Vitest;
- Capacitor Android/iOS;
- arquitetura reutilizável de jogos e evolução para sincronização/multiplayer quando implementada.

### 4. AI English Coach — opcional
Posicionamento: laboratório/open source de IA e workflow com memória versionada.

Mostrar apenas se o conjunto principal não ficar poluído. Serve para demonstrar documentação, contratos de agente, schemas, persistência de estado e uso prático de IA.

## Estrutura de cada case study
Cada projeto em destaque deve responder rapidamente:
1. O que é?
2. Qual problema resolve?
3. O que Renan implementou?
4. Qual é a stack?
5. Qual complexidade técnica merece destaque?
6. Onde posso ver o produto ou repositório, se público?

## Sobre mim
Evitar cinco ou mais parágrafos longos. Estrutura recomendada:
- resumo profissional em 2 parágrafos curtos;
- experiência corporativa relevante;
- forma de atuação end-to-end;
- objetivo atual sem texto genérico.

## Stack
Agrupar em vez de exibir apenas uma linha de ícones:
- **Frontend:** React, Next.js, TypeScript, Tailwind CSS.
- **Backend:** C#, ASP.NET/.NET, APIs/Server Actions conforme aplicável.
- **Dados:** PostgreSQL, Supabase, SQL Server.
- **Mobile/Infra:** Capacitor, Docker, Vercel, GitHub Actions quando comprovado pelos projetos.
- **IA:** LLMs, RAG, embeddings, pgvector e agentes somente onde houver experiência prática demonstrável.
