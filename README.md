# Portfólio — Renan Xavier

Portfólio pessoal de Renan Xavier, Desenvolvedor Full Stack.

A versão atual apresenta projetos e experiência profissional com foco em produto, frontend, backend, dados, mobile, segurança e práticas de IA, preservando a identidade visual original do site.

## Projetos em destaque
- **AWX / All Wheels Experience** — plataforma autoral de gestão automotiva.
- **Cursos Pugliese** — plataforma full stack de cursos com autorização, regras de negócio e segurança.
- **Galerows** — coleção de jogos sociais com base web/mobile.

## Stack apresentada
- Frontend: React, Next.js, TypeScript e Tailwind CSS.
- Backend: C# / .NET e server-side Next.js.
- Dados: PostgreSQL, Supabase e SQL Server.
- Mobile/Infra: Capacitor, Vercel e GitHub Actions.
- IA em projetos: LLMs, RAG, embeddings, pgvector e agentes.

## Implementação do portfólio
O portfólio permanece em HTML5, CSS3 e JavaScript, com layout responsivo, navegação acessível, suporte a `prefers-reduced-motion` e metadados para SEO/social sharing.
